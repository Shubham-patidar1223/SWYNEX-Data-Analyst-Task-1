# SWYNEX Technologies - Data Analyst Internship

## Task 1: Data Cleaning

This project is part of my Data Analyst Internship at SWYNEX Technologies.

### Objective

The objective of this task is to inspect and clean the given marketing campaign dataset so that it can be used for further data analysis.

### Tools Used

- Python
- Pandas
- VS Code
- GitHub

### Dataset

The dataset contains customer information, income, purchasing behavior, campaign responses, and other marketing-related attributes.

### Data Cleaning Steps

1. Loaded the dataset using Pandas.
2. Checked the dataset shape and column names.
3. Checked data types.
4. Identified missing values.
5. Checked duplicate records.
6. Inspected categorical values such as `Marital_Status` and `Education`.
7. Converted `Dt_Customer` into proper date format.
8. Filled missing `Income` values using the median.
9. Performed a final duplicate and missing-value check.
10. Saved the cleaned dataset as `marketing_campaign_cleaned.csv`.

### Project Files

- `task1.py` - Python code used for data cleaning.
- `marketing_campaign_cleaned.csv` - Cleaned dataset.
- `README.md` - Project documentation.

### Result

The cleaned dataset is ready for further analysis and dashboard development in the upcoming internship tasks.
